\section{Métodos de Instalación}

Se realizará la instalación del RBDMS en una edición Pro de Windows y adicionalmente mediante docker debido a que el instalador no tiene soporte para Sistemas Operativos como MacOS y ediciones Home de windows por lo que el servicio de manera contenerizada es una opción bastante cómoda y más escalable en comparación a las Máquinas Virtuales convencionales

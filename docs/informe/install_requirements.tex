\section{Requisitos de Instalación y Problemas Encontrados}

La documentación oficial manifiesta expresamente que la instalación del motor de base de datos especificado no soporta versiones de Windows en edición \textbf{Home}. Por lo tanto, para dar cumplimiento a la evidencia de aprendizaje, se usará una implementación contenerizada del RDBMS mediante Docker, dado que no disponemos de la edición del sistema operativo (en adelante, OS) exigida.

Aun teniendo esto en cuenta, se realizaron pruebas intentando instalar el motor directamente en el OS principal. Como se contemplaba a priori, surgieron errores de sistema que interrumpieron el proceso. El problema principal radicó en que, durante el flujo de configuración, el asistente no permitió la creación de la base de datos global o principal inicial, lo que imposibilitó de manera definitiva la implementación nativa en un entorno no soportado como Windows 11 Home.
